# Uni2-Hyde-English-Voice-Replacement
A mod for Uni2 that replaces Hyde's voicelines with his English voice from BBTAG (battle lines only, character interaction lines skipped, may eventually add other characters but idk)
Now a mod ran through Zanaylo's uni2 Improvement Mod, you'll need that one for this one to work. link: https://github.com/Zanaylo/UNI2-Improvement-Mod/releases/tag/0.7.5

DOWNLOAD INSTRUCTIONS:
1. download this folder: https://drive.google.com/drive/folders/1eCllFwCDgtTmeQXj1pMIK3SyAvKzH8gx?usp=sharing
2. drop it in the Packs folder in your UNI2-IM folder
3. Enable the mod in the F1 menu in game
4. enjoy!
